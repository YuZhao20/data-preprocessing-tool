📊 データ前処理ツール

機械学習や統計分析のためのデータ前処理を簡単に行うためのWebアプリケーションです。

アプリを開く →

※ Streamlit Cloudでデプロイ後、上記のURLを実際のアプリURLに置き換えてください

主な機能

  • データの読み込み・編集（CSV、Excel、JSON対応）
  • 欠損値処理（自動、KNN、MICEなど）
  • 外れ値処理（IQR、Z-score、Isolation Forestなど）
  • カテゴリ変数エンコーディング
  • 特徴量スケーリング・正規化
  • 高度な分析（重複削除、特徴量エンジニアリング、VIF分析、次元削減など）
  • データ可視化・統計検定

使い方

  1. ファイルをアップロード
  2. データを確認・編集
  3. 前処理設定を選択
  4. 前処理を実行
  5. 処理済みデータをダウンロード

注意: アップロードされたデータは一時的にのみ保存され、セッション終了時に自動的に削除されます。
