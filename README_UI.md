# Web UI 使用ガイド

文系学生にも簡単に使えるWebインターフェースを提供しています。

## 起動方法

### 1. 必要なライブラリのインストール

```bash
pip install -r requirements.txt
```

### 2. Streamlitアプリの起動

```bash
streamlit run app.py
```

ブラウザが自動的に開き、Webインターフェースが表示されます。

## 使い方

### ステップ1: データファイルのアップロード

1. 左側のサイドバーから「📁 データファイルのアップロード」セクションを確認
2. 「CSV、Excel、JSONファイルをアップロード」をクリック
3. データファイルを選択

**日本語ファイルの文字化け対策:**
- CSVファイルをアップロードすると、「🔤 エンコーディング設定」が表示されます
- 文字化けが発生する場合は、適切なエンコーディングを選択してください：
  - **自動検出**: プログラムが自動的に検出（推奨）
  - **UTF-8**: 一般的なUTF-8形式
  - **Shift-JIS (CP932)**: Windowsでよく使われる形式
  - **EUC-JP**: Unix/Linuxでよく使われる形式
  - **ISO-2022-JP**: メールなどで使われる形式

### ステップ2: 前処理オプションの選択

左側のサイドバーで以下のオプションを設定：

#### 1. 欠損値処理
- **auto**: 自動処理（推奨）
- **fill**: 欠損値を補完
- **drop**: 欠損値がある行を削除
- **knn**: KNN imputationを使用

#### 2. 外れ値処理
- チェックボックスで有効/無効を選択
- 方法を選択：
  - **iqr (IQR法)**: IQRの倍数を調整可能（デフォルト: 1.5）
  - **zscore (Z-score法)**: Z-scoreの閾値を調整可能（デフォルト: 3.0）
  - **isolation_forest (Isolation Forest)**: 外れ値の割合を調整可能（デフォルト: 0.1）

#### 3. カテゴリ変数エンコーディング
- **auto**: 自動選択（推奨）
- **label**: Label Encoding
- **onehot**: One-Hot Encoding

#### 4. 特徴量スケーリング・正規化
- **standard (標準化)**: 平均0、分散1に変換
- **minmax (0-1正規化)**: 0-1の範囲に正規化
- **robust (Robust scaling)**: 中央値と四分位数を使用
- **max_abs (最大絶対値)**: 最大絶対値でスケーリング
- **quantile (分位数変換)**: 一様分布に変換
- **quantile_normal (正規分布への変換)**: 正規分布に変換
- **power (Yeo-Johnson変換)**: 正規分布に近づける変換（負の値も扱える）
- **box_cox (Box-Cox変換)**: 正規分布に近づける変換（正の値のみ）
- **log (対数変換)**: 対数変換
- **sqrt (平方根変換)**: 平方根変換
- **なし**: スケーリングしない

#### 5. 特徴量選択
- チェックボックスで有効/無効を選択
- 選択する特徴量数を指定

### ステップ2.5: データの編集（オプション）

「✏️ データ編集」タブで、データを直接編集できます：

#### 🗑️ 削除
- **列を削除**: 不要な列を複数選択して削除
- **行を削除**: 行番号を指定して削除（例: 0,1,2 または 0-5）
- **セルを削除**: 特定のセルを欠損値に変換

#### 📝 編集・一括置換
- **列全体を置換**: 特定の値を一括して別の値に置換
- **条件付き置換**: 条件（以上、以下、等しい、含む）に基づいて値を置換
- **正規表現による置換**: 正規表現パターンにマッチする値を置換
- **セルの個別編集**: 特定のセルの値を直接編集

#### 🔄 並べ替え
- 列の値に基づいて行を並べ替え（昇順/降順）

#### ➕ 挿入・追加
- **列を追加**: 新しい列を任意の位置に挿入
- **行を追加**: 新しい行を任意の位置に挿入

#### ↔️ 入れ替え
- **列を入れ替え**: 2つの列の位置を入れ替え
- **行を入れ替え**: 2つの行の位置を入れ替え

**編集をリセット**: 「🔄 編集をリセット」ボタンで元のデータに戻せます

### ステップ3: 前処理の実行

1. 「📋 データプレビュー」タブでデータを確認
2. 「✏️ データ編集」タブで必要に応じてデータを編集
3. 「📈 データ情報」タブで変数の種類を確認
4. 「🔧 前処理実行」タブで「🚀 前処理を実行」ボタンをクリック

### ステップ4: 結果の確認とダウンロード

- 処理後のデータを確認
- 記述統計量を表示（オプション）
- グラフを表示（オプション）
- 統計検定を実行（オプション）
- 処理済みデータをCSVまたはExcel形式でダウンロード

## 機能一覧

### データプレビュー
- **閲覧モード**: データ全体を表示（スクロール可能）
- **編集モード**: セルを直接クリックして編集可能（Excelライクな操作）
- データの基本情報（行数、列数、欠損値、重複行）

### データ編集
- **削除機能**: 列、行、セルの削除
- **一括置換機能**: 
  - 列全体の値の一括置換
  - 条件付き置換（以上、以下、等しい、含む）
  - 正規表現による置換
- **編集機能**: セルの直接編集（データプレビューでも可能）
- **並べ替え機能**: 列の値に基づく並べ替え
- **挿入・追加機能**: 列や行の追加
- **入れ替え機能**: 列や行の位置入れ替え
- **リセット機能**: 編集を元に戻す

### データ情報
- 数値変数とカテゴリ変数の自動識別
- 欠損値の詳細情報

### 前処理実行
- 選択したオプションに基づいて前処理を実行
- 処理前後の比較
- 記述統計量の表示
- データの可視化（ヒストグラム、相関行列）
- 統計検定の実行
- 処理済みデータのダウンロード

## トラブルシューティング

### エラー: "ファイルを読み込めませんでした"

**原因**: エンコーディングの問題

**解決方法**:
1. ファイルをUTF-8形式で保存し直す
2. Excelファイルの場合は、CSV形式で保存してからアップロード

### エラー: "前処理中にエラーが発生しました"

**原因**: データ形式の問題

**解決方法**:
1. データが表形式（行と列）になっているか確認
2. 列名が1行目にあるか確認
3. 数値データが文字列として読み込まれていないか確認

### 処理に時間がかかる

**原因**: データサイズが大きい

**解決方法**:
1. データのサンプル（最初の1000行など）で試す
2. 不要な前処理オプションを無効化する

## よくある質問

### Q: どの前処理を選べばいいですか？

A: 初心者の方は、まずはデフォルト設定（すべて "auto"）で試してみてください。結果を見ながら、必要に応じて調整します。

### Q: 特徴量選択は必要ですか？

A: 変数が非常に多い場合（50個以上）に有効です。少ない場合は不要です。

### Q: 外れ値除去は必要ですか？

A: データに明らかな外れ値（異常に大きい/小さい値）がある場合に有効です。

### Q: 処理済みデータを保存できますか？

A: はい。「📥 処理済みデータのダウンロード」セクションから、CSVまたはExcel形式でダウンロードできます。
