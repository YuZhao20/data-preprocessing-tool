# データ前処理ツール

機械学習や統計分析のためのデータ前処理を簡単に行うためのWebアプリケーションです。

## 特徴

- 📊 **包括的な前処理機能**: 欠損値処理、外れ値検出、カテゴリ変数エンコーディング、特徴量スケーリングなど
- 🎯 **初心者向けUI**: プログラミングの知識がなくても、直感的な操作でデータの前処理が可能
- 🔧 **高度な分析**: 重複削除、特徴量エンジニアリング、VIF分析、クラス不均衡処理、次元削減など
- 📈 **データ可視化**: 統計量の表示、グラフの生成、統計検定の実行
- 📝 **処理履歴**: 実行したすべての処理を記録・表示

## インストール

### 必要な環境

- Python 3.8以上
- pip

### セットアップ

1. リポジトリをクローンまたはダウンロード
2. 依存パッケージをインストール:

```bash
pip install -r requirements.txt
```

## 使い方

### ローカルで実行

```bash
streamlit run app.py
```

ブラウザで `http://localhost:8501` にアクセスします。

### 基本的な使い方

1. **データのアップロード**: サイドバーからCSV、Excel、JSONファイルをアップロード
2. **データの確認**: 「📋 データ」タブでデータを確認・編集
3. **データの分析**: 「📊 分析」タブでデータを理解
4. **前処理設定**: サイドバーで前処理オプションを設定
5. **前処理実行**: 「⚙️ 前処理」タブで実行
6. **結果のダウンロード**: 処理済みデータをダウンロード

## 主な機能

### データ編集
- セル、列、行の編集・削除・追加
- 一括置換、条件付き置換、正規表現置換
- 列・行の並べ替え、入れ替え、移動

### 前処理機能
- **欠損値処理**: 自動処理、補完（平均/中央値/最頻値）、KNN、MICE、EMアルゴリズム
- **外れ値処理**: IQR、Z-score、Isolation Forest、MAD、Winsorize、Mahalanobis距離
- **カテゴリ変数エンコーディング**: Label、One-Hot、Ordinal、Target、Frequency、Count
- **特徴量スケーリング**: 標準化、Min-Max、Robust、Quantile、Power、Box-Cox、Log、Sqrt

### 高度な分析
- **重複削除**: 完全一致、キー列、類似度ベース
- **特徴量エンジニアリング**: 交互作用項、多項式特徴、ビニング、スプライン
- **VIF分析**: 共線性の検出
- **クラス不均衡処理**: SMOTE、ADASYN、Random Over/Under Sampling
- **データ分割**: ランダム、層化、時系列、グループ分割
- **次元削減**: PCA、MCA、UMAP、t-SNE
- **特徴量選択**: 相互情報量、RFE

### 統計分析
- 記述統計量の表示
- データの可視化（ヒストグラム、箱ひげ図、散布図、相関行列）
- 統計検定（正規性検定、等分散性検定、独立性検定）

## 対応ファイル形式
